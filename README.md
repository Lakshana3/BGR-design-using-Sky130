# BGR-design-using-Sky130
This repository is a work in progress.

## Overview
This repository contains course materials, lab exercises, and spice files from Analog Bandgap Reference design using Sky 130 - VSD Workshop. 

---

## Key Learning Outcomes
- Understand and derive CTAT (VBE) and PTAT (ΔVBE) voltages using BJTs.
- Design a self-biased current mirror with startup for supply-independent biasing.
- Combine CTAT + scaled PTAT (R2 = αR1) to generate temperature-stable VREF.
- Verify robustness using PVT corners, PSRR, tempco, and load regulation
